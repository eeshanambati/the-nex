              Always open as administrator

              Windows asks for your approval each time The Nex opens. While it is open, Restore, Delete and Always allow then do not ask again. Dragging a file onto the window does not work in this mode, because Windows blocks it.

              Scheduled scan

              Checks Downloads and Desktop on its own, quietly in the background, and only tells you when it finds something. It only reports: it never moves or deletes anything. It starts about 10 minutes after the Mac wakes, and it does not check the battery, so on a laptop it can run unplugged. If you start a scan yourself meanwhile, it stops and tries again later.

              Summary report

              Saves one readable page in your Downloads folder: what The Nex found, what it did and whether protection was on. It works even if the service is stopped, and nothing is sent anywhere.

              Report a problem

              Opens the report form on the website in your browser. The app itself sends nothing.
